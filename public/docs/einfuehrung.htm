Maschinennahe Programmierung mit Mnemo

Das Programm MNemo dient zum Programmieren eines Modellrechners, der auf der gleichen CPU wie auch die Simulationen CPU-Direkt und Altair beruht.
Im Gegensatz zu Letzterem, muss ein Programm hier aber nicht binär direkt in den Speicher eingegeben werden, sondern es kann in Form einer Textdatei vorbereitet werden.
Beispiel:

inm zahl1
inm zahl2
lda zahl1
add zahl2
sta summe
outm summe
stop

zahl1 def 0
zahl2 def 0
summe def 0

In dieser Textdatei wird ausschließlich mit den symbolischen Bezeichnungen (den sog. Mnemonics) der Befehle gearbeitet (daher auch der Name des Programms).
Ein weitere Unterschied besteht darin, dass statt der Angabe von Adressen, frei wählbare Bezeichner verwendet werden.
Statt
inm 16
schreibt man z.B.
inm zahl1

Um die Adresse der Speicherzelle so ersetzen zu können, muss man den Bezeichner (Namen) der Zelle im Programm vereinbaren. Dies geschieht mit Hilfe der DEF-Direktive in der Form
zahl1 def 0
Man schreibt also erst den gewünschten Bezeichner, dann def und dahinter muss festgelegt werden, welcher Wert beim Programmstart in dieser Zelle stehen soll.

Vor dem Programmstart wird die so erstellte Textdatei in den Binärcode (wie wir ihn vom Altair kennen) übersetzt. Ein solches Übersetzungsprogramm, das die Mnemonics in Binärcode übersetzt nennt man einen Assembler. Man spricht auch allgemein von Assembler-Programmierung.
Der Assembler ist auch dafür zuständig, dass den definierten Bezeichnern geeignete Speicherzellen zugeordnet werden.

Enthält das Programm Sprünge, kommt eine weitere Besonderheit zum Tragen.
Beispiel:

inm zaehler
anfang
  outm zaehler
  lda zaehler
  dec
  sta zaehler
jpl anfang
stop

zaehler def  0

Das Besondere ist hier, dass auch das Sprungziel durch einen Bezeichner (anfang) ersetzt wurde. Das Programm wird dadurch wesentlich verständlicher und Änderungen lassen sich einfacher durchführen.
