Transportbefehle               

Mnemo

 

Bedeutung

LDA

X

LOAD INTO AC

Lade (kopiere) den Wert der angegebenen Speicherzelle in den AC.

STA

X

STORE AC TO MEMORY

Kopiere den AC in die angegebenen Speicherzelle.

OUTM

X

OUTPUT FROM MEMORY

Kopiere den Wert der angegebenen Speicherzelle in die Output-Einheit.

INM

X

INPUT TO MEMORY

Speichere die von der Input–Einheit gelesene Zahl an der angegebenen Adresse ab. Das Programm hält bei diesem Befehl an und wartet auf die Eingabe der Zahl.

Besondere Befehle

STOP

 

STOP EXECUTION

Programm beenden.
NOP   NO OPERATION "Leerbefehl": Befehl ohne Wirkung

Arithmetische Befehle

ADD

X

ADD TO AC 

Addiere den Wert der angegebenen Speicherzelle zum AC.

SUB

X

SUBTRACT FROM AC

Subtrahiere den Wert der angegebenen Speicherzelle vom AC.
MUL X MULTIPLICATE WITH AC Multipliziere den Wert der angegebenen Speicherzelle mit dem AC.
DIV X DIVIDE WITH AC Dividiere den AC durch den Wert der angegebenen Speicherzelle.

AND

X

AC AND MEMORY

Verknüpfe jedes Bit des AC durch UND mit dem entsprechenden Bit der Speicherzelle X

OR

X

AC OR MEMORY

Verknüpfe jedes Bit des AC durch OR mit dem entsprechenden Bit der Speicherzelle X

XOR

X

AC XOR MEMORY

Verknüpfe jedes Bit des AC durch XOR mit dem entsprechenden Bit der Speicherzelle X

NEG

 

NEGATE AC

Negiere AC. (aus 1 wird 0 und umgekehrt)

INC

 

INCREMENT AC

Erhöhe den AC um 1.

DEC

 

DECREMENT AC

Vermindere den AC um 1.

SHL

 

SHIFT LEFT AC

Verschiebe alle Bits im AC um eine Stelle nach links.

SHR

 

SHIFT RIGHT AC

Verschiebe alle Bits im AC um eine Stelle nach rechts.

 Sprungbefehle

JMP

X

JUMP

Unbedingter Sprung. Springe zur angegebenen. Speicherzelle und fahre mit dem dort stehenden Befehl fort.

JMS

X

JUMP IF MINUS

Springe zur angegebenen Speicherzelle und fahre mit dem dort stehenden Befehl fort, wenn der AC negativ ist. Wenn nicht, dann fahre mit dem nächsten Befehl fort.

JPL

X

JUMP IF PLUS

Sprung, wenn AC größer 0.

JZE

X

JUMP IF ZERO

Sprung, wenn AC gleich 0.

JNM

X

JUMP IF NOT MINUS

Sprung, wenn AC nicht kleiner 0.

JNP

X

JUMP IF NOT PLUS

Sprung, wenn AC nicht größer 0.

JNZ

X

JUMP IF NOT ZERO

Sprung, wenn AC ungleich 0.

JSR

X

JUMP TO SUBROUTINE

Springe zum Unterprogramm an der angegebenen Adresse und fahre nach dem Rücksprung mit dem nächsten Befehl fort. Rücksprungadresse wird automatisch auf dem Stack abgelegt.

RTN 

 

RETURN FROM SUBROUTINE

Kehre vom Unterprogramm zurück zum Befehl nach der Aufrufstelle. Rücksprungadresse wird vom Stack geholt.

 Befehle für den eingebauten Assembler (keine Maschinenbefehle)

DEF Definiert einen Namen für die Adresse einer Speicherzelle. Zusätzlich muss der Wert der Zelle festgelegt werden. Die Reservierung von Speicherzellen für Variablen sollte stets am Ende des Programms erfolgen, damit es im Speicher nicht zu Überschneidungen von Programmbefehlen und Daten kommt.
 

Beispiel:
a DEF 0
Es wird eine Speicherzelle reserviert. Die Adresse der Zelle kann (muss) im Programm durch das Symbol a ersetzt werden.
Beispiel für Verwendung:
INM a
EQUAL Mit diesem Befehl wird eine symbolische Konstante definiert.
 

Beispiel:
offset EQUAL 3
Die so definierten Konstanten können nur bei den stackorientierten Befehlen verwendet werden und zwar dort, wo in der obigen Liste ein Y steht.
Beispiel für Verwendung:
STAS offset
