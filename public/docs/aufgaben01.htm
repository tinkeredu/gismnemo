Anspruchsvolle Aufgaben für den Modellrechner MNemo

 

1.         Folge der Quadratzahlen ausgeben

 

Der Benutzer kann einen Zahl n eingeben. Daraufhin gibt das Programm die Quadratzahlen

1, 4, 9, 16 … n2 aus.

 

Das Problem bei dieser Aufgabe ist, dass es in MNemo keinen Befehl für die Multiplikation gibt. Zwar kann man das Multiplizieren ganzer Zahlen durch eine wiederholte Addition ersetzen, dass ist programmtechnisch aber sehr aufwändig.

 

Ein alternativer Ansatz nutzt die Tatsache aus, dass sich jede Quadratzahl verhältnismäßig einfach anhand ihres Vorgängers berechnen lässt. Um das zu erkennen, solltest du die Differenzen zwischen aufeinander folgenden Quadratzahlen untersuchen.

 

 

 

2.         Der größte gemeinsame Teiler zweier natürlicher Zahlen (GGT).

 

Beispiel: der GGT von 44 und 12 ist 4.

Gesucht ist ein Programm, das nach Eingabe von zwei Zahlen, deren GGT anzeigt.

 

Für dieses Problem gibt es einen berühmten Algorithmus, der dem griechischen Mathematiker Euklid zugeschrieben wird. Informiere dich hierzu im Internet.

 

Der Euklidsche Algorithmus lässt sich mit MNemo programmieren!
